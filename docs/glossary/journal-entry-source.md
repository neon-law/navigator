---
title: "Journal Entry Source"
description: "The link between a Journal Entry and one Source Reference supporting it."
---

This internal join associates a [Journal Entry](journal-entry.md) with a [Source Reference](source-reference.md) within
the same Firm. A source link supplies evidence; it does not change the entry's recorded quantities.

The table is `journal_entry_source`.

Schema: [`journal_entry_source`](../../store/postgres/schema.sql).
