---
title: "Notation Document Version"
description: >-
  An immutable Markdown-source version of a Notation Document.
---

A parsed or edited version of a [Notation Document](notation-document.md), with its parent, author, and source assets.
Each edit appends a child version so the earlier work remains addressable.

The table is `notation_document_version`.

Schema: [`notation_document_version`](../../store/src/schema/navigator.surql#L1940).
