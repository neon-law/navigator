---
title: "Notation Preview"
description: >-
  A stored, expiring preview of a Template that has not been run.
---

A short-lived rendered [Template](template.md) preview in a [Project](project.md). It carries source for inspection
without creating a running [Notation](notation.md) or workflow journal.

The table is `notation_draft`.

Schema: [`notation_draft`](../../store/src/schema/navigator.surql#L1890).
