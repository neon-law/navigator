---
title: "Notation Creation Attempt"
description: >-
  A failed request to open a Notation and the run that resolves it, if any.
---

A Notation Creation Attempt records a failed request to open a [Notation](notation.md) on a [Project](project.md). It
records the Template code, respondent identifier, and failure time. A successful retry can link the failure to its
Notation. The record carries no submitted Answer values or error details.

The table is `notation_creation_attempt`.
