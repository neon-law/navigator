---
title: "Slack App"
description: "A workspace-installed Slack integration authorizing Navigator to call Slack APIs."
---

A Slack App is a provider-side integration installed in a Slack workspace. It authorizes a Navigator deployment to call
Slack APIs. The workspace's display name, installed identifiers, and deployment credentials are separate values. New
workspace installations use **Navigator** as the display name; a workspace administrator changes that display name in
Slack. It is provider configuration, not a Navigator row or a Person's [External System
Identity](external-system-identity.md).
