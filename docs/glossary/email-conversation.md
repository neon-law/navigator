---
title: "Email Conversation"
description: >-
  One threaded support exchange routed by an opaque reply token.
---

A support email thread whose reply token routes later hops to the same exchange. It may link to a running
[Notation](notation.md) and to a Firm or Project as the exchange is assigned.

The table is `email_conversation`.

Schema: [`email_conversation`](../../store/src/schema/navigator.surql#L2469).
