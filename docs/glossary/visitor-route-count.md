---
title: "Visitor Route Count"
description: >-
  An internal aggregate count of public website visits in one reporting bucket.
---

Internal counters for a [Brand](brand.md)'s public website, grouped by day, country, route pattern, source, locale, and
status class. These records carry counts without visitor identities.

The table is `visitor_route_count`.

Schema: [`visitor_route_count`](../../store/src/schema/navigator.surql#L1362).
