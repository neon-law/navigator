---
title: "Firm Calendar Settings"
description: >
  Firm Calendar Settings select the Google Workspace mailbox that owns a Firm's Project Calendars.
---

The Owner chooses the mailbox in [Firm](firm.md) Settings. This mailbox owns the Firm's
[Project Calendars](project-calendar.md). Clearing the mailbox disables Calendar provisioning.

The table is `firm_calendar_settings`.

Schema: [`firm_calendar_settings`](../../store/postgres/schema.sql).
