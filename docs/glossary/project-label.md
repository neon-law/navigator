---
title: Project Label
description: A Firm-defined classification that can be assigned to one or more Projects.
---

A **Project Label** is a reusable classification in a [Firm](firm.md)'s catalog. A category groups related labels for
filtering. A [Project](project.md) can carry several labels. Each label has a stable key, a display name, and a
category. Retiring a label hides it from active filters and prevents new assignments. Existing assignments remain
available on the Project.

Assignments are visible within the label's Firm. Firm administrators manage the catalog, and firm-side Project
participants manage assignments. The Projects page displays active labels and groups its filters by category. A
selection matches any chosen label within each category and requires a match in every selected category.

The table is `project_label`.

The table is `project_label_assignment`.
