---
title: "Expunge Request"
description: >-
  A client's request to delete one of their matter documents.
---

A request for lawyer review of a [Document](document.md)'s removal. An executed request links the resulting [Expunge
Record](expunge-record.md); pending and denied requests retain their decisions.

The table is `expunge_request`.

Schema: [`expunge_request`](../../store/src/schema/navigator.surql#L2244).
