---
title: Scope Amendment
description: A signed agreement expanding the work in an existing engagement.
---

A **Scope Amendment** is a signed agreement that adds defined work to an existing [Engagement /
Retainer](engagement--retainer.md). It names the original letter, states the new work, and records whether the scope
includes signing and filing pleadings. The original engagement letter governs the other terms. For [Legal Plan
Onboarding](legal-plan-onboarding.md), the Firm verifies any required plan authorization and agrees on additional fees
before undertaking the added work.

The shared `engagement_scope_amendment` [Template](template.md) collects the scope and both signatures.
