title: "Notation Document Comment"
description: >-
  A comment anchored to one block in one Notation Document Version.
---

An analysis finding or attorney note tied to a specific [Notation Document Version](notation-document-version.md). It
preserves its anchor and individual decision as the document gains later versions.

The table is `notation_document_comment`.
