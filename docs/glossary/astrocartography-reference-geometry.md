The fixed synthetic Sun upper meridian retains all 181 ordered vertices in a WGS84 MultiLineString with a GiST index.
The source fixture checksum, UTC instant, body, and angle identify the specimen. The migration owns writes and the runtime
role can read the reference. Personal calculation results are request-local.

The table is `astrocartography_reference_geometry`.
