---
title: "Inbox Attachment Filing"
description: "A lawyer-approved job that files one Inbox Message Asset as an internal Project document."
---

A lawyer approves one [Inbox Message Asset](inbox-message-asset.md) for a [Project](project.md) and selects its document
kind. The job records the Message, attachment position, Project, reviewer and review revision. The worker checks current
access and scans the source bytes before filing. Replays reuse the document identity and mail provenance.

The table is `inbox_attachment_filing`. See the [PostgreSQL definition](../../store/postgres/schema.sql).
