---
title: Daily Alert
description: >-
  The weekday notice a Firm's Owner receives when something needs them today, posted only when the needs-you list is not
  empty.
---

The **Daily Alert** is the [CEO Digest](ceo-digest.md)'s weekday companion. It posts to a [Firm](firm.md)'s Owner on
weekdays only when its needs-you list is not empty — an unanswered inbound older than two business days, a missed or
soon-due [deadline](deadline.md) — so a quiet day stays quiet. Like the digest, each of its figures is one journaled
query keyed to that Firm, and its post is deduplicated so a retried run never posts twice.
