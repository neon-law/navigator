title: "Inbox Assignment"
description: >-
  One audited assignment of a Conversation to a Project.

The actor and time of assigning a [Conversation](conversation.md) to a [Project](project.md). A reassignment appends
another record so the earlier assignment remains visible.

The table is `inbox_assignment`.
