title: "Email Conversation Message"
description: >-
  One append-only hop in an Email Conversation.

A single inbound or outbound message in an [Email Conversation](email-conversation.md), preserving its cleaned body and
any parsed reply directives. The latest hop supplies the conversation's current status.

The table is `email_conversation_message`.

Schema: [`email_conversation_message`](../../store/src/schema/navigator.surql#L2495).
