---
title: "Summary Sender Approval"
description: >-
  The current permission for a sender's messages to enter a Firm's summary intake.
---

An approval scoped to the [Firm](firm.md), provider account, and optional Project that admits a sender's messages to
[Email Receipt](email-receipt.md). Revocation changes the current approval while preserving its history.

The table is `summary_sender_approval`.

Schema: [`summary_sender_approval`](../../store/src/schema/navigator.surql#L1462).
