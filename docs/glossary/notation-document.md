title: "Notation Document"

One [Notation](notation.md)'s working document identity. It pins the original Word [Asset](asset.md) and points to the
current [Notation Document Version](notation-document-version.md).

The table is `notation_document`.

Schema: [`notation_document`](../../store/src/schema/navigator.surql#L1921).
